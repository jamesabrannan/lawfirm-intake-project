For a REST-only application, the current HTTP Basic authentication works without a login page:

  1. The client sends an Authorization: Basic … header containing the Base64-encoded email and password on each request.
  2. Spring Security’s filter chain extracts those credentials.
  3. The JDBC authentication service retrieves the password and role from users, using email as the username.
  4. Valid credentials with role paralegal or lawclerk allow access. Missing or invalid credentials return 401; an authenticated user without an allowed role receives 403.

Postman’s Basic Auth option creates this header. With curl:

curl -u jordan.ellis@example.com:password http://localhost:8080/api/paralegal-assignments

Base64 is encoding, so deployed Basic authentication needs HTTPS.
